# Edinburgh Capital Greenspace Website 

An interactive geospatial web application designed to support Edinburgh's urban forestry goals by balancing carbon sequestration capacity with social equity prioritization.

# Project Overview
The central element of this project is an interactive Leaflet-based WebGIS interface that allows decision-makers, stakeholders, urban planner and the public to explore Edinburgh's public greenspaces. The tool bridges environmental remote sensing (LiDAR-derived carbon stock) with socio-economic data (Scottish Index of Multiple Deprivation) to optimize future tree-planting locations.

# Key UI Features & Capabilites 

**Interactive Map & Zoning: ** Full-screen map of Edinburgh with public greenspaces highlighted in green
