# Edinburgh Capital Greenspace Website 

An interactive geospatial web application designed to support Edinburgh's urban forestry goals by balancing carbon sequestration capacity with social equity prioritization.

# Project Overview
The central element of this project is an interactive Leaflet-based WebGIS interface that allows decision-makers, stakeholders, urban planner and the public to explore Edinburgh's public greenspaces. The tool bridges environmental remote sensing (LiDAR-derived carbon stock) with socio-economic data (Scottish Index of Multiple Deprivation) to optimize future tree-planting locations.

# Key UI Features & Capabilities 

Interactive Map & Zoning: Full-screen map of Edinburgh with public greenspaces highlighted in green, brownspaces in brown, and surrounding areas in neutral tones.

KPI Tracker: A top-screen progress counter tracking city-wide tree-planting progress toward the 1-million-tree goal. 

# Layer Toggling & Analysis
Layer 1 (Current Carbon Stock): Purple gradient choropleth highlighting high vs. low carbon storage.

Layer 2 (Environmental Deprivation Index): Visualizes local socioeconomic need to identify underserved neighborhoods.

Layer 3 (Proposed Planting Zones): A dual-color gradient heatmap highlighting high-priority intervention zones (e.g., high deprivation paired with low canopy cover).

Equity vs Carbon Slider: A 5-step priority weighting slider allowing users to dynamically shift between Prioritize Carbon Capture and Prioritize Social Equity.
